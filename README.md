# Linux Basics Notes

## What is Linux?
Linux is an open-source operating system widely used in servers, cloud environments, and security systems. It allows users to interact with the system using commands through a terminal.

---

## Basic Linux Commands

### ls
Lists all files and directories in the current working directory.

### cd
Used to change directories and navigate between folders.

### pwd
Displays the full path of the current working directory.

### cp
Copies files or directories from one location to another while keeping the original file.

### mv
Moves files or directories to another location or renames them.

### rm
Deletes files or directories permanently. This command is dangerous because deleted data cannot be easily recovered.

---

## Why Linux is Important in Security
Linux provides full control over files, users, and processes. Many cloud servers and security tools run on Linux, making it essential for cybersecurity and cloud roles.
